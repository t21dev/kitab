# Packaging

- `windows/kitab.rc` embeds the app icon (id 1, used by GPUI for the window and taskbar) and the document icons (101 PDF, 102 EPUB, 103 Markdown, 104 MOBI, 105 FB2, 106 CBZ, 107 XPS, 108 TXT) in `kitab.exe` (`crates/kitab/build.rs`). File associations point at them as `kitab.exe,-<id>`. Kitab writes them per user from Settings › Reading › Default app (`kitab-os::assoc`); the MSI (Phase 10) writes the same keys.
- `macos/Info.plist` declares the document types and icons (`Kitab.icns`, `doc-*.icns`), with `LSHandlerRank` Alternate. `@VERSION@` is filled from the workspace version at bundle time.
- `linux/dev.t21.kitab.desktop`, `linux/dev.t21.kitab.xml` (shared-mime-info) and `linux/icons/hicolor/` go to `/usr/share/applications`, `/usr/share/mime/packages` and `/usr/share/icons`.

All icons are generated by `tools/make_icons.py`; edit the script, not the files.

## Thumbnails

Every system uses `kitab --thumbnail` (crate `kitab-thumb`): page 1 of a document, or a page preview of Markdown and text. It runs as its own short process and exits before any window code.

- Linux: `linux/dev.t21.kitab.thumbnailer` goes to `/usr/share/thumbnailers/`. GNOME Files, Nemo, Caja and Thunar (tumbler) then call `kitab --thumbnail -s SIZE IN OUT.png`. KDE Dolphin uses its own plugins.
- Windows: `kitab_thumb.dll` (crate `kitab-shell`) is the Explorer thumbnail provider. It pipes the file to `kitab.exe --thumbnail --stdin EXT --bgra` next to it, so MuPDF ships once and a bad file can't crash Explorer.
- macOS: a Quick Look thumbnail extension, with the macOS build.
