    In development · Phase 0

    Every document. One fast window.

    Kitab Reader opens PDF, EPUB, Markdown and comics in tabs that remember where you were. Native, drawn on the GPU, and built to open as fast as SumatraPDF.

    Follow on GitHub Release status

    Free and open source (AGPL-3.0). Windows first, then macOS and Linux.

    1. 01

      Tabs that come back

      Open as many documents as you like. Restart, and every tab returns on the same page, at the same zoom.

      • Pin, reorder, reopen a closed tab
      • Home shows what you were reading
    2. 02

      Pages keep their shape

      Portrait, landscape and receipt-sized pages sit together at one zoom, each at its own size.

    3. 03

      Find, the same everywhere

      Ctrl+F in a PDF, a book or a Markdown file. Match case, whole word, accents ignored, and a list of every hit.

    4. 04

      Markdown, rendered properly

      Tables, task lists, highlighted code with a copy button, Mermaid diagrams and math. It reloads when you save.

    5. 05

      Forms that add up

      Fill every kind of field. Currency, dates and totals work the way the form expects, and no script inside the PDF ever runs.

      • Save a copy, export or import the data
      • Password-protected files of every standard kind
    6. 06

      Signatures you can trust

      See whether a signature is valid and whether the file changed after signing. Sign with a certificate that never leaves your computer.
