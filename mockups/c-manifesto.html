Kitab Reader · PDF, EPUB, Markdown, comics

A reader should open before you notice.

Kitab is a native, GPU-drawn reader with one rule above the rest: it has to start as fast as SumatraPDF on the same machine, or the change that slowed it down doesn't ship.

Follow on GitHub Read the plan

On speed

Measured againstSumatraPDF. Not claimed.

The same files, the same machine, a stopwatch that watches the window. Fifteen runs per scenario. Results ship with every release, along with the machine they ran on. Until the first release, there is no number on this page.

What Kitab promises

Your files.Your computer.

  • 01

    No telemetry. Ever.

    No analytics, no crash uploads, no account. Nothing leaves unless you send it.

  • 02

    No document runs code.

    PDF scripts never run. Forms still add up: Kitab works out totals and dates itself.

  • 03

    Keys stay local.

    Sign PDFs with a certificate that never leaves your machine. Open password-protected files of every standard kind.

  • 04

    Everything in one window.

    PDF, EPUB, MOBI, FB2, XPS, CBZ, Markdown with Mermaid and math. Tabs that come back after a restart.

  • 05

    Free, and the source is open.

    AGPL-3.0. The plan, the design system and the tests are public.

  • 06

    Installs the way you install things.

    Installer, portable zip, DMG, AppImage, Flatpak, and from the first release brew, scoop and winget.
